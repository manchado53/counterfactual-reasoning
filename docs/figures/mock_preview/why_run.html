02 / How a reading is actually taken

No new training. We take a frozen brain (a saved snapshot) and make it answer "what if I took action A here, then played normally?" from every state, many times. Every metric is just a statistic over those playouts. Click a step.

On disk: a finished training run = one folder with brain snapshots (Q-net weights saved every N episodes) and metrics.log (win rate per episode). Nothing is retrained — we only read.
Pick 4 snapshots: random · 10% · 30% · BEST. "Best" = the highest-win checkpoint, NOT the last — FL DQN often collapses late (final checkpoint can be 0% win).
Load the brain: open the .pkl → the Q-network weights → pour them into an agent. The agent now plays exactly like that snapshot.
Env + states: rebuild the matched env (deterministic or slippery) and list the 53 decision cells of the 8×8 grid (drop holes + goal). We score all of them.
The atom: for each state, force each action then follow the brain's greedy moves to the end → a discounted return. Repeat 60×. Stack → returns[53×4×60] (next panel).
Squeeze: every metric is a statistic of that one tensor (plus one exact value-iteration solve and one greedy visit-count). See the fan-out below.
Validate: re-evaluate the loaded brain's win rate and compare to metrics.log. Match → right checkpoint. Mismatch / best<20% → STOP (the past failure mode).

04 / So — why run it?

Three reasons, in one breath:

1. Prove the rulers aren't lying — do the real numbers match the case we know cold?
2. Turn the mock dashboard into a real one — preview numbers become measured numbers, with checkpoint + win-rate provenance.
3. Earn the right to forecast — once calibrated, the same cheap rulers predict new environments before we commit GPUs.

And if a reading had disagreed with the known truth — that's the most valuable result of all: a ruler is broken, fix it before trusting any forecast. (This run: SNR matched both baths ✓; GAIN-fidelity did NOT — flagged for repair.)
