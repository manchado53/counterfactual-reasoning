# Value scores in place of rollout CCE

Approved on October 21, 2026 after the user required the saved winning setup and a score-only change. Tracks issue #47.

We will test whether the learned action values can pick useful replay data at less cost than simulated futures. Q(s,a) means the model's expected future reward for action a at state s. The proposed score compares Q(s,a) for the stored action with Q(s,b) for the other legal actions. It uses the target network, the slowly updated copy already used in training. No new value model is needed.

Use absolute action-value gaps, |Q_target(s,a)-Q_target(s,b)|. Keep each reference arm's aggregation rule explicit: JaxNav uses its existing weighted mean and action weights; FrozenLake uses the effective max over alternatives in its historical scorer. Freeze these choices before launch. This replaces distributional rollout differences with differences in learned means; it is a proxy, not an equivalent CCE estimator. A raw state value V(s) is a different experiment. This proposal uses action values.

The JaxNav reference is the fixed-collector, CCE-only decay arm in experiments/jaxnav/ranked-td-decay/training.json (task 33 for seed 0): sparse 8x8, fill 0.3, fixed 1,000-map bank seed 20260923, up to 200k episodes, score-to-ranked-TD fade from 100k to 150k. Preserve its score timing, rank transform, mixing, and learning settings. Replace both replay and drift-probe scores with value gaps in the value arm; preserve their call sites and parent random-key advancement; log zero scoring simulator calls. Keep diagnostic overhead explicit in timing.
