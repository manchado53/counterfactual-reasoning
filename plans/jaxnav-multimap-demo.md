# JaxNav multi-map README demo

Replace the one-map JaxNav animation with a short sequence of shared fixed
evaluation maps. Each arm will receive the same initial state and step keys on
each map. The video will label map number, outcome, and steps, and it will show
at least one real CCE success without hiding the other displayed outcomes.

The map set will use a documented deterministic rule from the existing
1,000-map bank. The provenance file will record every map, checkpoint hash,
and arm outcome. Tests will guard shared-map use and selection metadata. The
README will keep the learning curve as the statistical result and call the
video an illustration.
